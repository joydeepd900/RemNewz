## 1. Telegram Bot Token (`TELEGRAM_BOT_TOKEN`)

The Telegram Bot Token allows RemNewz to send messages, process commands, and interact with you.

### Instructions for @BotFather

1. Open Telegram and search for [@BotFather](https://t.me/BotFather) (verify the blue verification checkmark).
2. Tap **Start** or send `/start`.
3. Send `/newbot`.
4. BotFather will ask for a **display name** for your bot:
   - Example: `My RemNewz Assistant`
5. Next, choose a **username** for your bot. It **must** end in `bot` (case-insensitive):
   - Example: `remnewz_personal_bot` or `my_remnewz_bot`
6. BotFather will reply with your token in this format:

   ```text
   Use this token to access the HTTP API:
   7123456789:AAFlKj9_ExampleTokenStringHere_ABC123
   ```

7. **Copy this token** and save it in your password manager. This is your `TELEGRAM_BOT_TOKEN`.
8. **CRITICAL STEP:** Click the link to your bot in BotFather's message (e.g., `t.me/your_bot_username`), open the chat, and click **Start** (or send `/start`). The bot cannot message you until you start the conversation!

## 2. Telegram Chat ID (`TELEGRAM_CHAT_ID`)

RemNewz enforces a strict security allowlist: it only responds to your specific chat ID and drops messages from unauthorized users.

### How to Get Your Chat ID

#### Method A: Auto-Detection via `setup.py` (Easiest)

If you use the automated setup wizard (`python setup.py`):

1. The wizard will prompt:

   ```text
   How would you like to provide your Telegram Chat ID?
   1. Auto-detect (Send '/start' to your bot on Telegram)
   2. Enter Chat ID manually
   ```

2. Simply select `1`, open Telegram, and send `/start` to your bot.
3. The wizard listens to the Telegram API and automatically captures your Chat ID!

#### Method B: Browser Lookup via Telegram API

If setting up manually or if auto-detection is not used:

1. Ensure you have sent at least one message (e.g., `hello` or `/start`) to your bot.
2. In your web browser, navigate to:

   ```text
   https://api.telegram.org/bot<YOUR_TELEGRAM_BOT_TOKEN>/getUpdates
   ```

   *(Replace `<YOUR_TELEGRAM_BOT_TOKEN>` with the token from Step 1)*.
3. Look for the `"chat"` object inside the JSON response:

   ```json
   "chat": {
     "id": 123456789,
     "first_name": "Jane",
     "username": "jane_doe",
     "type": "private"
   }
   ```

4. Copy the numeric `id` value (`123456789`). This is your `TELEGRAM_CHAT_ID`.

#### Method C: Using `@userinfobot`

1. In Telegram, search for [@userinfobot](https://t.me/userinfobot).
2. Tap **Start**. It will immediately reply with your personal numeric Telegram user ID.

> [!NOTE]
> If you plan to use RemNewz inside a **Telegram Forum Supergroup**, the chat ID will be a negative number (e.g. `-1001234567890`). See the [User Guide](user_guide.md#5-telegram-supergroups--forum-topic-routing-optional) for details.

## 3. Google Gemini API Key (`GEMINI_API_KEY`)

Google Gemini is the default AI provider for RemNewz (`gemini-2.0-flash`). Google AI Studio provides a free tier with 15 requests per minute, which is more than sufficient for RemNewz.

### Instructions for Google AI Studio

1. Visit [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Sign in with your Google account.
3. Click **Create API key** (or **Get API key**).
4. Select **Create API key in new project** (or pick an existing Google Cloud project).
5. Copy the generated key string (starts with `AIzaSy...`).
6. Store it securely. This is your `GEMINI_API_KEY`.

> [!TIP]
> **Prefer Groq or OpenRouter?**
>
> RemNewz supports pluggable AI providers:
> - **Groq:** Get a free API key at [console.groq.com/keys](https://console.groq.com/keys). Set `AI_PROVIDER=groq` and `AI_MODEL=llama-3.3-70b-versatile` with secret `GROQ_API_KEY`.
> - **OpenRouter:** Get a key at [openrouter.ai/keys](https://openrouter.ai/keys). Set `AI_PROVIDER=openrouter` with secret `OPENROUTER_API_KEY`.
> - Note: The automated `setup.py` wizard currently configures Google Gemini by default. You can easily switch providers later in **GitHub Repository Secrets**.

## 4. GitHub Personal Access Token (`GITHUB_PAT`)

The GitHub Personal Access Token (PAT) is required for:

1. Enabling the **Cloudflare Worker** to trigger instant GitHub Actions runs (`repository_dispatch`).
2. Allowing the automated `setup.py` wizard to automatically write secrets to your repository.
3. Giving the GitHub repository fetcher a higher API rate limit (5,000 req/hr vs 60 req/hr).

### Method A: Fine-Grained Personal Access Token (Recommended)

1. In GitHub, click your **Profile icon** (top right) $\to$ **Settings**.
2. Scroll to the bottom of the left sidebar $\to$ **Developer settings**.
3. Select **Personal access tokens** $\to$ **Fine-grained tokens**.
4. Click **Generate new token**.
5. Configure the token:
   - **Token name:** `RemNewz Dispatcher`
   - **Expiration:** Choose your preferred lifespan (e.g. 90 days, 1 year, or custom).
   - **Repository access:** Choose **Only select repositories** $\to$ Select your `RemNewz` repository.
6. Under **Repository permissions**, configure:
   - **Contents:** Change to **Read and write** *(Required for `repository_dispatch` triggers)*.
   - **Secrets:** Change to **Read and write** *(Required if you want `setup.py` to auto-provision GitHub Secrets without `gh` CLI)*.
   - **Actions:** Change to **Read and write** *(Recommended)*.
7. Click **Generate token** at the bottom.
8. Copy the token (starts with `github_pat_...`).

### Method B: Classic Personal Access Token (Alternative)

1. Go to **Developer settings** $\to$ **Personal access tokens** $\to$ **Tokens (classic)**.
2. Click **Generate new token** $\to$ **Generate new token (classic)**.
3. Set **Note:** `RemNewz Token`.
4. Check the **`repo`** scope box (full control of private repositories).
5. Click **Generate token** and copy the string (starts with `ghp_...`).

## 5. Cloudflare Account (For Instant Webhook Proxy)

RemNewz uses a lightweight Cloudflare Worker (`scripts/cf_worker_proxy.js`) to provide **instant, sub-second bot replies** and avoid using GitHub Actions minutes when idle.

### Instructions for Cloudflare Setup

1. Go to [Cloudflare Sign Up](https://dash.cloudflare.com/sign-up).
2. Create a free account (no credit card required).
3. If running the automated setup wizard (`python setup.py`):
   - The wizard will run `npx wrangler deploy`.
   - A browser window will open asking you to authorize Wrangler with Cloudflare. Click **Allow**.
   - The wizard will automatically deploy your worker, set the secrets, and bind your Telegram webhook!
4. If setting up manually:
   - Follow the detailed steps in the [Cloudflare Worker Guide](cloudflare_worker_guide.md).

## 6. Database Encryption Key (`ENCRYPTION_KEY`)

RemNewz encrypts your entire database (`remnewz.db.enc`) using AES-128-CBC Fernet encryption before committing it to GitHub. This enables you to safely use a **free Public repository** without exposing personal tasks or settings.

- **If using Automated Setup (`python setup.py`):**
  - **Zero action required!** The wizard automatically generates a cryptographically secure 32-byte Fernet key and provisions it to your GitHub Secrets.
- **If using Manual Setup:**
  - Run this one-line Python snippet on your computer or in terminal:

    ```bash
    python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode('utf-8'))"
    ```

  - Copy the resulting base64 string and save it as your `ENCRYPTION_KEY` GitHub Secret.
